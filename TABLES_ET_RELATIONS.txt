TABLE 1 : users
====================================================================
Colonne           | Type          | Contraintes
------------------|---------------|----------------------------
id                | UUID (String) | PK, auto-généré
firstName         | String        | NOT NULL
lastName          | String        | NOT NULL
email             | String        | NOT NULL, UNIQUE
password          | String        | NOT NULL
role              | UserRole      | NOT NULL (enum)
roles             | String(500)   | Multi-rôles séparés par ","
avatarUrl         | String        | Nullable
clubId            | String        | FK logique → clubs.id
managedClubIds    | String(1000)  | IDs séparés par ","
createdAt         | Instant       | NOT NULL, auto

Relations :
  • users.clubId → clubs.id (club principal géré, pour CLUB_ADMIN)
  • Un User peut gérer plusieurs clubs (managedClubIds)

RÉSUMÉ DES CARDINALITÉS
====================================================================

  User  1 ──── N  Membership        (un user a plusieurs adhésions)
  Club  1 ──── N  Membership        (un club a plusieurs membres)
  User  1 ──── N  Club              (un admin gère N clubs)
  Club  1 ──── N  Event             (un club organise N événements)
  Event 1 ──── N  EventRegistration (un événement a N inscrits)
  User  1 ──── N  EventRegistration (un user s'inscrit à N événements)
  User  1 ──── N  Notification      (un user reçoit N notifications)
  User  1 ──── N  ClubRequest       (un user fait N demandes)
  User  1 ──── N  ChatLog           (un user a N conversations)
  User  1 ──── N  UserSession       (un user a N sessions)
  Club  1 ──── N  Announcement      (un club a N annonces)
  Club  1 ──── N  Document          (un club a N documents)
  User  1 ──── N  Announcement      (un user crée N annonces)

====================================================================
NOTE : Toutes les relations sont "logiques" (pas de @ManyToOne JPA).
Les FK sont stockées comme des String (UUID) sans contrainte JPA
relationnelle. C'est une architecture dénormalisée volontaire.
